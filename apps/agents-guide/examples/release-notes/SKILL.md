# Release notes

Read `references/style.md` before drafting.

1. Extract only the supplied changes and checks.
2. Group the changes under Added, Changed, and Fixed when applicable.
3. Use the sections Summary, Changes, and Verification.
4. Never invent test results, features, version numbers, or release dates.
5. If no test results were supplied, write "Verification not provided".
6. This skill drafts text only. Do not modify files, execute host commands, or publish a release.
